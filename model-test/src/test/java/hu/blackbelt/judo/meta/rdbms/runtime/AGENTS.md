# `model-test/src/test/java/hu/blackbelt/judo/meta/rdbms/runtime` — dual-engine (EVL vs Zeta/Java) validation tests, `RdbmsUtils` query tests, Excel→RDBMS incremental round-trip test

| File | Purpose |
|---|---|
| `AbstractRdbmsValidationTest.java` | Shared fixture running one test body against both validation engines. Exports `initModel()` (builds `rdbmsModelSupport` over `urn:Rdbms.model` plus empty `rdbmsModel`), `runValidation(expectedErrors, expectedWarnings)` dispatching on field `validatorType`, plus `runEvlValidation(...)` / `runJavaValidation(..., [parallel])`. Subclass must set `validatorType` and call `initModel()` per test; unset type throws `IllegalStateException`. |
| `RdbmsExecutionContextTest.java` | Smoke test that `RdbmsModelResourceSupport` accepts builder-created content without a backing file. `testRdbmsReflectiveCreated` builds support over file URI `urn:rdbms.judo-meta-rdbms`, adds `newRdbmsTableBuilder().withFullName("TEST")`, prints `asString()`. Asserts nothing — fails only when building or serializing throws. |
| `RdbmsIncrementalTest.java` | End-to-end incremental-diff round trip. `executeExcel2RdbmsModel` runs `createRdbmsModelsFromExcel.etl` over `RdbmsIncrementalTests.xlsx` + `mapping.xml` into wrapped EMF models `ORIGINAL_MODEL`/`NEW_MODEL`, calls `RdbmsIncremental.transformRdbmsIncrementalModel(orig, new, incremental, "hsqldb", true)`, asserts result via `testIncrementalModel.etl`. Scripts and workbook resolved from test classpath root. |
| `RdbmsRealWorldPerformanceTest.java` | `@Tag("performance")` benchmark on a synthesized production-shaped model. Generates `TABLE_COUNT` (property `rdbms.perf.tables`, default 80) tables × `FIELDS_PER_TABLE` (`rdbms.perf.fieldsPerTable`, default 12) plus foreign keys, junction tables, indexes; times EVL vs Java sequential vs parallel. `Random(42)` fixes generated shape. |
| `RdbmsUtilsTest.java` | Behavioural tests of `RdbmsUtils` lookups over builder-created models: `getRdbmsTables`/`getRdbmsTable`, `getAllRdbmsField`/`getRdbmsFields`/`getRdbmsField`, `getRdbmsForeignKey(s)`, `getRdbmsJunctionTable(s)`. Pins that every lookup returns `Optional.empty()` before model content exists, that `uuid` equals `name` for init builders (`Tables.TestTable`), and that a fresh table carries exactly one `_id` field. |
| `RdbmsValidationEquivalenceTest.java` | Asserts EVL and Zeta validators flag identical constraints on one model. Generates rackinspect-shaped model (83 tables, 137 FKs, 12 junction tables, 11 indexes, weighted `FIELD_TYPES_WEIGHTED`, seed `42`); compares via `assertEquivalentResults` over `RdbmsElementNameNotEmpty`, `RdbmsElementUuidNotEmpty`, `RdbmsElementNameIsUnique`, `RdbmsTableHasPrimaryKey`. EVL failures mentioning `RdbmsPackage` count as passes. |
| `RdbmsValidationPerformanceTest.java` | `@Tag("performance")` scaling benchmark on a flat generated model. `testPerformanceWith10000Elements` builds `ELEMENT_COUNT` = 10000 elements (tables plus `RdbmsIdentifierField`/`RdbmsValueField`) and logs EVL, Java-sequential, Java-parallel durations and ratios; `testPerformanceWith1000Elements` is the quick variant. Timings only — no assertion fails on a slow run. |
| `ValidatorType.java` | Enum selecting validation engine for parameterized tests. `EVL` routes to `RdbmsEpsilonValidator`, `JAVA` routes to `hu.blackbelt.judo.meta.rdbms.validation.RdbmsValidator`. Fed to `@EnumSource(ValidatorType.class)`; new constant needs a matching branch in `AbstractRdbmsValidationTest.runValidation` or tests hit its `IllegalStateException`. |
